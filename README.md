# Preproute Test Management Application

Frontend assessment project built using React, TypeScript and REST APIs.

## Features

- Login Authentication
- Dashboard with Test Listing
- Create Test
- Add Questions
- Preview Test
- Publish Test
- API Integration
- Responsive UI

## Tech Stack

- React
- TypeScript
- React Router
- Axios
- Bootstrap
- SCSS
- React Toastify

## Setup

npm install

npm start

## Deployment

Hosted on Vercel
